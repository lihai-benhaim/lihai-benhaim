# מפת דרכים

## שלב 0: גרסה 0.1 (מה שיש עכשיו)

משתמש אחד, רץ על ה-NAS. וואטסאפ + אתר, Claude לתכנון ומחקר, וידאו ב-ffmpeg, Instagram + LinkedIn, אישור קשור לגרסה, dry-run.

## שלב 1: שימוש יומיומי אמין

- [ ] **תזמון**: "תפרסם מחר ב-9" (שדה `scheduledFor` בטיוטה + טיימר; תבנית WhatsApp לתזכורת מחוץ לחלון 24 השעות).
- [ ] **תוקף טוקנים**: תזכורת בוואטסאפ שבוע לפני שטוקן של LinkedIn/Instagram פג, עם קישור לחיבור מחדש. רענון אוטומטי של long-lived token באינסטגרם.
- [ ] **Retry לפרסום**: על שגיאות `retryable` (429, 5xx), עם backoff, ופרסום חוזר רק של היעדים שנכשלו.
- [ ] **תמונות מהטלפון**: נרמול כיוון EXIF והמרת HEIC לפני הרינדור (sharp).
- [ ] **סאונד**: ספריית מוזיקה קטנה לפי `musicMood` שהסוכן בוחר; קריינות (TTS) כאופציה.
- [ ] **רינדור HTML** (Remotion/Playwright) לצד ffmpeg: טיפוגרפיה עשירה יותר, ושורות שמערבבות עברית ואנגלית בסדר הנכון (ffmpeg drawtext מסדר שורות מעורבות לא תמיד נכון).
