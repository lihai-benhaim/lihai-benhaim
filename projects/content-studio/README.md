# Content Studio

סטודיו תוכן אישי: אתה מתאר במשפט מה אתה רוצה לפרסם (בוואטסאפ או באתר), הוא עושה את המחקר, כותב, מבקש ממך את התמונות שחסרות לו, מרנדר סטורי/וידאו, ושולח לך תצוגה מקדימה לאישור. רק אחרי שאתה לוחץ "לפרסם", הוא מפרסם בשמך בכל הרשתות שחיברת.

```
אתה (וואטסאפ / אתר)                  הסטודיו (רץ על ה-NAS)
─────────────────────               ──────────────────────────────────────────
"סטורי על ההשקה, גם ללינקדאין"  →   Claude: מחקר + תסריט + כיתוב לכל רשת
                                ←   "צריך ממך: סלפי מול המחשב"
📷 תמונה                         →   ffmpeg: וידאו 9:16 + תמונת שער 4:5
                                ←   🎬 תצוגה מקדימה + [✅ לפרסם] [✏️ לשנות] [❌ לבטל]
"תקצר את הטקסט"                  →   גרסה 2 (האישור הקודם כבר לא תקף)
✅ לפרסם                         →   Instagram ✓  LinkedIn ✓  →  "פורסם" + קישורים
```

| חלק | מצב |

| בקשת תמונות מהמשתמש, וידאו 9:16 עם טקסט בעברית, תמונת שער 4:5 | ✅ (ffmpeg) |
| תצוגה מקדימה ואישור בוואטסאפ (כפתורים) ובאתר | ✅ |
| **אישור קשור לגרסה**: כל שינוי אחרי האישור מחייב אישור חדש | ✅ |
| חיבור חשבונות ב-OAuth (לחיצה על "חבר") | ✅ |
| פרסום: Instagram (סטורי, ריל, פוסט תמונה), LinkedIn (טקסט, תמונה, וידאו) | ✅ קוד + בדיקות מול API מדומה. צריך אפליקציות מפתחים ([docs/platforms.md](docs/platforms.md)); עוד לא נוסה מול החשבונות האמיתיים |

## התחלה מהירה (על המחשב)

```bash
pnpm install
cp .env.example .env          # מלא APP_SECRET_KEY ו-STUDIO_ADMIN_TOKEN (פקודות בתוך הקובץ)
echo "PLANNER=template" >> .env   # בלי מפתח API: תבנית קבועה במקום Claude, רק כדי לראות את הזרימה
pnpm dev                      # http://localhost:8080
pnpm check                    # typecheck + כל הבדיקות
```

עם `ANTHROPIC_API_KEY` ו-`PLANNER=claude`, התוכן נכתב על ידי Claude.

## הרצה על ה-NAS

מדריך מלא: **[docs/nas-setup.md](docs/nas-setup.md)**. בקצרה:

```bash
docker compose --profile tunnel up -d --build
```

## מבנה

```
packages/core         מודל הנתונים, מכונת המצבים של טיוטה, מגבלות כל רשת, ולידציה
packages/agent        Claude: מחקר → תוכנית תוכן (structured output) → תיקון אוטומטי אם חרג ממגבלה
packages/media        רינדור ffmpeg: וידאו 9:16 עם זום איטי וטקסט RTL, תמונת שער 4:5
packages/publishers   מתאמי פרסום (Instagram, LinkedIn, Dry run) + OAuth
apps/server           Fastify: וואטסאפ, API, OAuth callbacks, מדיה חתומה, אתר הסטודיו
docs/                 ארכיטקטורה, רשתות, התקנה על NAS, מפת דרכים
```

פרטים: [docs/architecture.md](docs/architecture.md) · מה כל רשת דורשת: [docs/platforms.md](docs/platforms.md)

## עקרונות

1. **שום דבר לא יוצא בלי אישור.** האישור נקשר ל-hash של הכיתובים ושל קבצי המדיה. שינוי אחרי אישור = אישור חדש.
2. **לא ממציאים עובדות.** הסוכן כותב רק מה שבבריף, בתמונות או במקורות שמצא, ושואל כשחסר.
3. **הטוקנים שלך נשארים אצלך.** מוצפנים (AES-256-GCM) על ה-NAS. אין צד שלישי באמצע.
4. **רק המספר שלך.** הבוט בוואטסאפ מתעלם מכל מספר אחר; כל webhook נבדק בחתימה.
